# editorial_studio — 작업 범위 지침

## 목적
주제 1개당 5개 카테고리 중 1개를 선택하여 고정된 어조, 논조, 독자 관점, 전개 순서와 이미지 제작 정책을 적용한다. 이 영역은 과거 7단계 Notion·Naver 운영 자동화의 호출 지점이 아니다.

## 필수 읽기 순서
1. `editorial_studio/intend.md`와 `editorial_studio/RESEARCH_STYLES_2026-10-25.md`
2. 주제 결정 후 `editorial_studio/profiles/{선택된카테고리}.md` 단 한 개
3. 실제 구현 시 `editorial_studio/studio.py`와 `editorial_studio/README.md`

## 스타일 일관성
같은 카테고리는 **동일한 프로필 MD**, 말투·논조·5개 이야기 역할을 사용한다. 다른 주제더라도 목소리는 그대로 둔다. 실제 소제목 문구는 소재별로 달라질 수 있다. 다른 카테고리 지침을 혼합하지 않는다. 파일 SHA-256 불일치나 선택 근거가 모호할 때에는 작업을 통과로 기록하지 않는다.

## 근거와 이미지
글의 주장은 웹 검색 요약이 아니라 확인한 출처 원문에서 나온다. 검색 색인 발췌는 원문 검증으로 간주하지 않는다. 실제 경험·방문·관람·구매를 창작하지 않는다. 모든 이미지가 독자에게 추가 정보를 제공해야 하며, 가짜 통계·모조 공문서·권리 침해 이미지·저해상도 자리표시자를 사용하지 않는다. 생성되지 않은 이미지를 완료로 표기하지 않는다.

## 금지 작업
Notion·네이버 계정 쓰기, 임시저장, 게시·발행, 운영 계정 변경, 유료 리소스 추가, 역사 로그 보정·필수 테스트 약화. 옛 기능은 소스 보존만 하며, 이 독립 모듈에서 호출하지 않는다.

## 검증 정직성
구조 검사로 어조·사실·이미지 미감을 자동 검증했다고 주장하지 않는다. 실기능 CI가 녹색이어도 사람 편집 검수를 반드시 별도로 표시한다.
