## 말투와 논조
- **문체:** 분석적이고 간결한 합니다체. 수치·비교 기준·원인과 결과를 명확히 구분한다.
- **글의 관점:** 숫자→변화→가능한 원인→생활상의 영향 순서로 설명하며 상관관계를 곧바로 인과관계로 단정하지 않는다.
- **도입 공식:** 최신 확인 수치의 값·단위·기간·공개 기관을 밝힌 다음 '왜 중요한지'를 한 문장으로 설명한다.

## 고정 전개 순서
1. `## 이번 수치의 의미`
2. `## 어떤 변화가 있었나`
3. `## 변화의 원인과 한계`
4. `## 생활·시장에 미치는 영향`
5. `## 정리와 데이터 출처`

## 편집자 규칙
- 숫자가 있는 문장에는 단위·기준 시점·비교 대상을 함께 제시한다.
- 통계로 확인된 설명과 해석 가능한 가설을 별도로 표시한다.
- 투자·금리 전망은 가정과 불확실성을 밝혀 단정적으로 권유하지 않는다.

## 이미지 스타일
- **고정 표현:** 가독성 좋은 정량 그래프와 비교표 중심. 모든 축·기간·단위·출처를 표기한다.
- **시각 구성:** 대표 이미지: 숫자 하나를 강조하되 기준 기간을 명시. 본문: 출처 데이터의 시계열 그래프 1개, 원인/영향 개념도 1개. 실데이터 없는 수치·그래프 생성 금지.
- 사진이나 이미지 생성물은 사실 증거를 대신하지 못합니다. 출처·저작권·생성 여부를 별도로 표시합니다.

- `저도 매수했`

## 범위와 금지 규칙
- 이 파일은 해당 **카테고리 전용 스타일의 단일 기준**입니다. 다른 카테고리의 문체나 이미지 규칙을 합치지 않습니다.
- 웹에 공개된 객관적 자료만 인용합니다. 검증한 사실, 자료에서 이끌어낸 해석, 아직 확인되지 않은 내용을 구분합니다.
- 조사 과정을 1인칭으로 말할 수 있지만, 실제 경험·관람·방문·인터뷰·계약을 꾸며 쓰지 않습니다.
- 실제 자료를 확인하지 않았다면 숫자와 출처를 만들어 넣지 않습니다. 이미지가 아직 생성되지 않았으면 이미지 생성 완료라고 표기하지 않습니다.
- Notion 저장·네이버 자동 입력·임시저장·발행은 이 독립 편집 작업의 범위가 아닙니다.
