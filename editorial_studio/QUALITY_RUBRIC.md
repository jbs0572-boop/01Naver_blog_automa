# 검색 유입 목표와 채점 기준의 버전 관리

## 최종 목표
네이버 검색 등에서 오는 **실제 자연 유입의 증가**입니다. 발행 전 객관식 자동 점수는 유입을 예측할 때 참고하는 대리 지표이며 유입 실측값이 아닙니다. 사람의 실제 경험을 위조하거나 키워드만 반복해 올리는 글은 실격입니다.

## 100점 루브릭

| 항목 | v1 (기준선) | v2 (강화안) | 의미 |
|---|---:|---:|---|
| 근거 연결·보전 | 25 | 25 | 주장·출처·섹션 ID 추적, 원문 사실관계는 별도 사람 대조 |
| 5종 카테고리 어조·구조 | 20 | 15 | 프로필 단일 적용, 지침 해시·5개 편집 역할·금지문구 |
| 검색 의도 일치 | 15 | 20 | 질문과 제목·첫 문단의 답변 일치, 낚시성 금지 |
| 고유한 독자 가치 | 15 | 15 | 근거 밀도·본문의 충분한 설명, 의미 없는 반복 금지 |
| 이미지 완성도 | 15 | 20 | 고해상도·화소 정보량·깨짐 검사, 실제 관련성/미감은 육안 |
| 모바일 가독성 | 10 | 5 | 이미지 alt, 모바일 미리보기, 소제목과 문단 구성 |
| **합계** | **100** | **100** | 서로 다른 버전 점수를 그대로 비교하면 안 됨 |

v2는 저품질 이미지의 기계적 통과 문제를 개선하기 위한 **실험적 기준 강화안**입니다. 점수가 높아졌다는 이유만으로 실제 유입 개선을 주장하지 않습니다.

## 무조건 차단·수정할 사항
- 출처 확인되지 않은 사실이나 지표, 블로그에서 복제한 본문, 조작된 경험·체험 후기
- 5개 프로필 중 둘 이상 혼합, 스타일 해시 불일치, 이미지 미생성 상태의 완성 처리
- 1280×720 미만, 유효하지 않은 PNG, 지나치게 균일한 이미지, 출처 없는 실제 수치 그래프
- 과장 제목, 본문과 무관한 키워드, 중복 이미지로 카테고리 문서 양산
- 사진이나 생성 이미지에 관한 권리 및 사실성 미검수

80/85점은 **검수 후보 점수**이지 게시 승인이나 SEO 예측 정확도가 아닙니다. 사람의 근거 대조·문체·이미지 적합도·저작권 검수 없이는 발행 가능으로 만들지 않습니다.

## 반복 검증과 안전한 루브릭 업그레이드
1. 최초 v1 정의, 난이도별 테스트 10개, 결함 반례(빈 이미지, 저해상도, 위조된 메타데이터, 프로필 오선택, 중복 이미지)를 **동결**합니다.
2. 각 카테고리 **다른 주제 2개 이상**에서 동일 MD 해시, 가변 소제목, 근거 보전, 이미지 프롬프트의 차이를 검사합니다. 수정 후 같은 테스트에 재검증합니다.
3. v2는 동결 v1과 같은 케이스를 재채점하며 각 항목 및 결함을 보고합니다. 가중치를 임의 변경해 유리한 점수로 보이게 하지 않습니다.
4. 품질 게이트를 강화한 버전이 **다른 홀드아웃 주제**에서 문제를 더 잘 적발하고 통과율만 높이지 않는 경우에만 채택합니다. 일단 v1 수치는 보존합니다.
5. 실제 글을 사용자가 발행한 뒤 소유자의 동의를 받아 **동일 검색어/기간 기준 노출수·자연 검색 클릭수·CTR·유입 세션·게시물별 업데이트 시점**을 기록합니다. 이 데이터가 없는 동안 최종 목표 달성률은 **측정 불가**입니다.
6. 최소 4주 이상 사전 기록한 동일기간 지표와 비교하되 발행일·계절성·키워드 난이도·기존 사이트 권위를 구분합니다. SEO 유입은 외부 환경 영향을 받으므로 스타일 점수 상승을 인과효과라 주장하지 않습니다.

## v3 이후 점수표의 자동 제안 프로세스

`python -m editorial_studio.evolution --feedback reviewed.json --out rubric-v3-proposal.json` 명령은 **실제 사람의 개별 평가**가 누적된 뒤에만 후보를 생성합니다.

- 최소 15개의 독립적으로 검수된 글, 학습 10개 이상·평가용 홀드아웃 5개 이상, 다섯 카테고리에서 각 2개 이상이 필요합니다.
- 필드: `case_id`, `category`, `set` (`train`/`holdout`), `human_review` (`pass`/`fail`), `failure_reasons`, `dimensions` (6개 차원별 실제 관측값 0~1).
- 사람이 자주 지적한 `image_offtopic`, `blurry_image`, `false_claim`, `wrong_search_intent` 등의 반례에서 개선해야 할 항목을 선택합니다.
- 근거·이미지 하한 가중치는 낮출 수 없습니다. 홀드아웃에서 **나쁜 글을 좋은 글로 오판한 횟수가 감소하고, 좋은 글의 누락이 늘지 않아야** 새 루브릭 후보로 기록합니다.
- 후보를 생성해도 구버전 `v1/v2` 파일을 자동 수정하거나 배포하지 않습니다. 사람이 읽고 검증한 뒤에만 별도 버전 승격을 결정합니다.
- 실제 유입에 대한 인과 효과는 이 테스트로 증명할 수 없습니다. 유입 로그가 없을 때 실제 클릭수는 `null`입니다.

**주요 반례:** 이미지가 없는데도 단순히 글쓰기 점수만 높아서 검수 완료로 보이는 경우는 v2에서 이미지 0점 및 수정 요청으로 명확히 처리합니다. 마찬가지로 초안용 이미지 프롬프트만 존재하는 것은 `image_generated=true`의 근거가 아닙니다.
