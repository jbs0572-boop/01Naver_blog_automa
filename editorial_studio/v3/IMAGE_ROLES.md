# 원본 우선 이미지 계약

- 글마다 최소 3개의 **서로 다른 역할**의 이미지를 요구한다.
- 1. **맥락 실사진**: 사용 권한이 확인된 원본을 그대로 복사하고 해시 보존, 본문에 큰 원본으로 표시. 공식 스틸/과거 실제 화면은 실제 촬영 사진과 구분해서 표기한다.
- 2. **근거/정보 비교**: 승인된 근거팩에 있는 실제 문장 3개로 HTML/CSS 인포그래픽 제작, 숫자·날짜 임의 창작 금지.
- 3. **실행 전 점검**: 주제와 관련 있는 실제 확인 순서를 시각화, 새 사실을 만들어 넣지 않는다.
- 각 이미지 캡션은 사진/그래픽의 **용도만 짧게** 설명하고 페이지 하단의 근거 링크와 혼동하지 않는다.
- 대표 이미지 재사용으로 개수만 늘리는 행위를 금지한다. 세 파일 해시와 시각 역할은 서로 달라야 한다.
- 새 외부 사진은 권리 확인 범위에 포함되었다는 기록이 있을 때만 자동화에 사용한다. 원본 사본의 SHA-256을 기록한다.
- HTML/CSS 시각물은 Chromium에서 인포그래픽 내부 글자 영역·가로 오버플로·화면 로딩과 PNG 픽셀을 확인한다. 실패 시 세 번을 넘겨 임의 시각물을 만들지 않는다.
- 세 이미지의 SHA-256이 하나라도 동일하면 역할 이름만 바꿔 재사용한 것으로 보고 실패한다. 사진 크레딧/원문 URL/라이선스 정보는 이미지 용도 캡션과 별도의 출처 줄로 보존한다.
