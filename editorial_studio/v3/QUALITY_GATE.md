# 자동 품질 평가 — 고정 100점 계약

**목표: 95점 이상**이며 모든 필수 안전·근거·시각 검사를 동시에 통과해야 한다. 점수는 서식 및 데이터 연결 **대리지표**이며 사람의 사실/저작권/미감 검증이나 실제 검색 유입 증가를 증명하지 않는다.

| 차원 | 점수 | 실제 검사 |
| --- | ---: | --- |
| 근거 문장 연결 | 22 | 공개된 소스팩과 원문 링크·5개 사실 ID 사용 |
| 카테고리 전용 구조 | 15 | 다섯 문단과 독립 카테고리 테마 |
| 원본 보존 | 18 | 다운로드 원본과 로컬 사본 SHA-256 일치 |
| 이미지 역할 다양성 | 18 | 원본·정보 비교·점검 그래픽 각 1개 이상 |
| 실제 브라우저 검사 | 20 | PC·모바일·글자 잘림·카드 내부 오버플로 |
| 본문 반복 방지 | 7 | 동일 섹션 본문 반복 없음 |
| **합계** | **100** | 자동 98점 상한(사람 검수 미완료) |

Q1 자동 검사가 통과하더라도 인간 검수=PENDING, 발행=false로 남긴다. 점수·키워드·이미지를 늘리기 위한 근거 없는 반복을 금지한다. 3회 실패한 레이아웃은 원인을 기록하고 중단한다.
