# V3 원본 우선 블로그 제작 워크플로 — intend.md

## 목적
근거·원고를 사람이 확인한 자료에서 가져오고, 한 카테고리 스타일만 적용하며, 정보 역할이 서로 다른 최소 3개의 이미지를 결합한 네이버 블로그 검수 전 초안을 제작한다. 실제 게시와 네이버 유입은 수행·측정하지 않는다.

## 카테고리와 글별 목적 고정
`editorial_studio/topics/{category}/intend.md`는 조사·독자 질문·이미지 역할·통과 기준의 독립 원본이다. 각 글 출력 폴더의 `intend.md`에는 실제 기사 제목·근거 기준일·원문 대조 보류 및 SHA-256을 남긴다. 사람 검수·네이버 계정 쓰기 승인을 대신하지 않으며 파일 누락 또는 계약 불일치 시 중단한다.

## 자동 수행 영역
1. 원본 아티팩트 압축파일 읽기, 파일 무결성 확인, 이미지 출처 메타데이터 보존.
2. 카테고리 결정, 원고/근거 ID 연결, 중복·금지 표현 검사.
3. 원본 사진 + 출처 기반 비교 정보 그래픽 + 실행 전 점검 그래픽의 최소 세 역할 구성.
4. HTML/CSS 작성 → Playwright Chromium 캡처 → 카드 내부 글자 좌표와 텍스트 절단 검사 → 최대 세 번 글꼴 수정.
5. PC·모바일 전체 화면 검사와 이미지 해시, 100점 자동 평가, 증거 JSON·PNG·HTML 저장.

## 사람이 갱신할 Markdown 규칙
- 기존 profiles/life_health.md 등 다섯 독립 MD가 글쓰기 문체/말투/구성을 정의한다. 다른 카테고리 규칙을 혼합하지 않는다.
- IMAGE_ROLES.md는 사진 사용 우선순위, 이미지 역할, 최소 개수, 짧은 이미지 설명 규칙을 고정한다.
- QUALITY_GATE.md는 점수표와 반드시 통과해야 하는 결함 검사 기준을 고정한다.
- 최종 사실관계·권리·미적 완성도 검수 결과는 사람이 별도로 입력한다. CI 통과는 발행 승인이 아니다.

## 실행 조건과 중단 조건
소스팩/사진을 확인할 수 없거나 3개 시각 역할이 없거나, 텍스트가 카드 바깥으로 넘치거나 원본 해시가 불일치하면 실패한다. 점수 95점 미만이면 실패한다. 재시도는 레이아웃 변경만 허용하며 텍스트/근거 삭제로 통과시키지 않는다.

## 현재 범위
실시간 LLM 집필, 네이버/Notion 계정 접근, 자동 발행, 유료 API 호출, 실제 검색 유입 측정 기능은 이 단계에 없다.
## 추가 자동 무결성 계약
섹션마다 근거 ID가 1개 이상 있어야 하며, ID의 역할·원문 소속이 입력팩과 일치해야 한다. 동결 프로필 SHA-256, 세 이미지 SHA-256 상호 차이, 원본 파일 해시 및 본문 사진 크레딧/URL을 검증한다. 어느 하나라도 오류면 자동 점수가 95 이상으로 나오더라도 게이트 실패다.

## 새 주제 입력·원고 혼합 방지
각 카테고리의 `cases.json` 편집 제목·도표·체크리스트는 오직 `source_topic`과 `source_as_of`가 정확히 일치하는 원본 근거팩에만 결합한다. `영화 기생충` 원문을 `헤어질 결심` 제목으로 조립하는 등 같은 카테고리의 다른 주제끼리 혼합하면 브라우저 이미지 생성 전에 실패한다. 날짜 역시 보존하며 자동으로 현재 날짜로 바꾸지 않는다.
