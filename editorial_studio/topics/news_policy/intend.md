# 뉴스·정책·이슈 — 주제 기획·조사·글·이미지 제작 의도 (intend.md)

## 목적
기사 제목과 실제 제도 사이의 시행시점·적용대상·예외가 달라 혼란을 겪는다.

**검색 의도:** 무엇이 바뀌었는지, 언제부터 누구에게 적용되고 원문은 무엇인지

**답변 약속:** 핵심 변화·시행일·대상·예외를 원문으로 대조하고 독자 행동에 영향을 주는 부분을 먼저 말한다.

## 자료 조사 및 원문 검증
**무엇을 조사하는가**

- 기존 제도와 신규 변경 사항의 정확한 차이
- 발표일·시행일·유효기간의 구분
- 대상자·제외 대상·기한·절차의 공식 확인

**원문 출처 우선순위 (실시간 검증을 수행했다는 뜻은 아님)**

1. 법령 원문·관보·정부 또는 규제기관 공식 공고
2. 해당 기관의 시행 안내·원문 FAQ·정정 공지
3. 원문을 교차 검증할 수 있는 신뢰 가능한 보도

**사실 검증 체크**

- 발표·입법예고·공포·시행을 같은 단계로 오인하지 않았는가
- 기준일·지역·적용 대상이 제목과 본문에서 동일한가
- 발표 자료가 수정되거나 정정되었는가

## 본문 구성
독자에게 필요한 정보 역할을 다음 순서로 채웁니다. 본문 소제목 표현은 각 기사에 맞게 바꾸고 기계적으로 복제하지 않습니다.

1. 오늘의 핵심 결론
2. 공식 원문과 시점
3. 변경 이전과 이후
4. 적용 대상·예외
5. 공식 확인 방법·업데이트 기록

## 이미지 원본 사용과 생성 의도
**우선 확보할 실제 원본:** 출처와 시점을 확인한 실제 공식 발표 화면·공고문 일부(정확한 정보 이미지); 공식 문서처럼 보이는 생성 이미지는 사용하지 않음

- `context-photo`: 검증된 보도 맥락의 공식 스크린샷 또는 실제 발표 현장 사진
- `information-graphic`: 구제도/신제도·발표/시행의 시간순 비교 도식
- `action-checklist`: 대상 여부·적용일·확인 경로를 정리한 점검표

- 권리·크레딧·원본 URL과 파일 SHA를 보존하고, 승인된 실제 이미지를 우선 사용합니다.
- 그래픽은 출처팩의 확인된 내용만 사용해 HTML/CSS → Playwright로 캡처하고 PC·모바일 글자·정렬을 검사합니다.
- 세 이미지가 서로 다른 정보를 보충해야 하며 동일한 장식 카드 3장을 통과시키지 않습니다.

## 성공 기준과 중단 조건
**독자의 성공:** 독자가 소문과 공식 사실을 구분하고 자기 적용 여부를 확인할 수 있다.

**다시 조사할 때:** 정정 보도·법령 확정·시행일 변경·후속 고시 또는 FAQ 갱신 때 즉시 재검토

- 중단 — 날짜·대상을 확인하지 않은 속보형 제목
- 중단 — 공고·보도자료의 문구를 맥락 없이 복제
- 중단 — 확인되지 않은 시행 단정

- 제목과 본문이 약속한 답을 일치시키고, 모든 핵심 주장에 원문 출처 ID와 기준일을 연결합니다.
- 모바일·데스크톱 실제 화면에서 깨진 이미지·텍스트 잘림·출처/캡션 누락이 없어야 합니다.
- 기계적 품질 점수 95/100 이상이어도 사실관계·미감·권리와 공개 발행의 사람 승인은 별도로 필요합니다.
- 원문을 실제로 읽지 않았다면 검수됐다고 표시하지 않습니다. 네이버/Notion 저장과 자동 발행은 이 파일만으로 승인되지 않습니다.
