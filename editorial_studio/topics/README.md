# 다섯 카테고리의 기획 의도 파일

프로필은 HOW(문체·디자인), 이 경로의 개별 `intend.md`는 WHY/WHAT/WHERE(독자 목적·조사·증거·이미지 역할)를 정의합니다.

1. [생활·건강](life_health/intend.md)
2. [뉴스·정책](news_policy/intend.md)
3. [영화·인물](culture_people/intend.md)
4. [부동산](real_estate/intend.md)
5. [경제](economy/intend.md)

버전 관리된 각 문서는 사람이 읽는 규칙과 ```intent` JSON 구조를 모두 포함합니다. 검증기는 글별 새 `intend.md`를 생성하고 SHA-256으로 고정합니다. 근거팩 내용의 진위·출처 권리·사람 검수·네이버 발행은 별도의 승인 조건입니다.
