# 부동산 — 주제 기획·조사·글·이미지 제작 의도 (intend.md)

## 목적
거래 사례와 조건이 다른데도 가격 한 건이나 기사 수치로 매입·계약 결정을 서두를 위험이 있다.

**검색 의도:** 실거래·제도 자료의 조건과 시점을 비교해 합리적인 점검 기준 얻기

**답변 약속:** 거래·공시·호가의 차이와 계약·면적·층·기간 조건을 점검하고 독자에게 실제 확인 경로를 안내한다.

## 자료 조사 및 원문 검증
**무엇을 조사하는가**

- 거래 유형·계약일·신고일·주소 등 데이터 범위
- 면적·층·동/단지·권리관계 등 비교 조건
- 실거래 수치와 현재 매물 호가·추정 시세의 차이

**원문 출처 우선순위 (실시간 검증을 수행했다는 뜻은 아님)**

1. 국토교통부 실거래가 공개시스템 및 원문 공고
2. 한국부동산원·법제처·지자체 공식 데이터
3. 확인 가능한 사업자 공고·보조 시세 자료

**사실 검증 체크**

- 계약일과 공개·신고 시점이 섞이지 않았는가
- 다른 면적·거래유형·층을 같은 가격 비교군으로 놓지 않았는가
- 시세·미래 수익률을 단정하지 않는가

## 본문 구성
독자에게 필요한 정보 역할을 다음 순서로 채웁니다. 본문 소제목 표현은 각 기사에 맞게 바꾸고 기계적으로 복제하지 않습니다.

1. 자주 생기는 착각
2. 공식 용어·데이터 범위
3. 실제 비교 조건
4. 예외·정보의 시차
5. 계약 전 체크리스트

## 이미지 원본 사용과 생성 의도
**우선 확보할 실제 원본:** 출처와 권리가 확인된 실제 단지·현장 사진 또는 공식 자료 화면; 허구의 매물·거래내역 스크린샷 금지

- `context-photo`: 실제 단지·지역·공식 발표 자료의 맥락 사진
- `information-graphic`: 실거래 사례의 면적·층·계약일·거래유형 비교표(실제 수치가 있을 때만)
- `action-checklist`: 등기·계약일·거래유형·신고 상태의 확인 순서 카드

- 권리·크레딧·원본 URL과 파일 SHA를 보존하고, 승인된 실제 이미지를 우선 사용합니다.
- 그래픽은 출처팩의 확인된 내용만 사용해 HTML/CSS → Playwright로 캡처하고 PC·모바일 글자·정렬을 검사합니다.
- 세 이미지가 서로 다른 정보를 보충해야 하며 동일한 장식 카드 3장을 통과시키지 않습니다.

## 성공 기준과 중단 조건
**독자의 성공:** 독자가 숫자를 비교하기 전 확인해야 할 동일 조건과 공적 확인 경로를 갖는다.

**다시 조사할 때:** 거래 신고 수정·취소·법령·대출·세제 변화 또는 새 기준일이 생길 때

- 중단 — 근거 없는 투자 수익 보장
- 중단 — 가짜 매물 사진·거래내역
- 중단 — 호가와 실거래가 혼용

- 제목과 본문이 약속한 답을 일치시키고, 모든 핵심 주장에 원문 출처 ID와 기준일을 연결합니다.
- 모바일·데스크톱 실제 화면에서 깨진 이미지·텍스트 잘림·출처/캡션 누락이 없어야 합니다.
- 기계적 품질 점수 95/100 이상이어도 사실관계·미감·권리와 공개 발행의 사람 승인은 별도로 필요합니다.
- 원문을 실제로 읽지 않았다면 검수됐다고 표시하지 않습니다. 네이버/Notion 저장과 자동 발행은 이 파일만으로 승인되지 않습니다.
