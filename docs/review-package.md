# 계획과 벤치마크 결과의 PR 검토 범위

이 PR은 생성 속도 최적화 계획과 조립 예비시험 결과를 검토하기 위한 문서 변경이다.
최적화 구현이나 운영 전환을 포함하지 않는다. GPT-6 Astra가 계획을 갱신하고,
사용자가 구현을 요청하면 GPT-6 Luna가 로컬 프로젝트에서 구현할 예정이다.

프로젝트의 목적은 네이버 블로그 글·이미지 품질을 유지하거나 높이면서 생성 시간과 반복 실패 비용을 줄이는 것이다.
자동 코드 리뷰는 이 목적을 지원하는 검토 기능이며, 같은 저장소의 변경을 검토한다.
GitHub의 PR 번호는 개별 변경 요청의 식별자다. 프로젝트 안내는 [README.md](../README.md)를 따른다.

## 원격 코드와 로컬 조사 자료의 차이

- PR 기준 커밋: `776ba8db3c2da97edeea6d36a427ec481b838da0` (`origin/main`).
- 조사한 로컬 HEAD: `053e48a`. 원격보다 앞선 기존 커밋 8개와 추가 미커밋 변경이 있다.
- Plan.md와 제안서는 그 로컬 작업 트리를 조사한 문서다. `기존 대상`으로 적힌
  일부 파일은 이 PR의 원격 checkout에 없으며, 원격 현재 상태의 실행 보증이 아니다.
- 기존 커밋·미커밋 운영 코드·실험용 Python 코드는 이번 PR로 일괄 게시하지 않는다.
  후속 구현 PR은 필요한 기준 코드를 먼저 검토해 반영한 뒤 별도로 만든다.
- 원래 프로젝트의 변경·로그·이미지·생성 글은 그대로 보존한다.

### 자동 리뷰에서 확인된 계약 차이

계획 리뷰의 목표 계약은 [최신 로컬 계약 snapshot](reference/local-operating-contract-2026-09-27.md)으로 고정했다.
원본은 2026-09-27 로컬 `AGENTS.md`이며, 파일 SHA-256은 `dc95921ebf0b2596e4df1b837284c77a6f329766a8bd93cbf8d7ada1c2db0abb`이다.
snapshot은 원본 byte를 보존한다. 그 안의 9절에 남은 네이티브 리뷰 연결 미완료 표시는 원본의 과거 상태 문구이며,
아래 실제 연결·실행 증거가 현재 상태다. snapshot 자체가 원격 코드의 구현 완료나 외부 쓰기 권한을 의미하지 않는다.

루트 AGENTS.md의 Code Review Rules는 계획과 실제 코드 변경의 검토 기준을 명시한다.

이 변경은 계획 리뷰 기준을 정합하게 만드는 것이며, 로컬 운영 코드를 원격으로 동기화하는 작업은 아직 수행하지 않았다.

커밋 `57564089d4`의 첫 Codex 리뷰는 2026-09-27에 완료되었다.
두 지적은 원격 AGENTS.md의 `Q3 필수`와 `최종 Markdown 세 개` 규칙을 근거로 한다.

구현 전 코드·스키마·검사기·운영 계약을 일치시키고, 같은 revision에서 다시 검토해야 한다.
최신 계약을 예전 규칙으로 되돌리는 수정이나, 근거 확인 없이 지적을 해결 처리하는 것은 하지 않는다.

## 포함된 증거

Plan.md, 최적화 제안서, 조립 시험 규칙, 두 모델 호출의 요약 JSON,
프로그램 5회 측정 JSON과 상세 보고서를 포함한다. 수치는 원자료와 대조했다.
프로그램 실행 중앙값은 0.685초지만 두 모델 실행이 모두 검증에 실패하여
유효한 절감률은 없다. 전체 20~30%·중심 25%는 미검증 예상이다.

`benchmarks/assembly_smoke/protocol.md`는 로컬 실험 규칙을 보존한 문서다.
그 안의 실행 명령은 실험 코드와 입력 자산이 있는 원래 로컬 프로젝트용이며,
이번 PR의 checkout만으로 재현할 수 있다는 뜻이 아니다.
보고서에 언급한 원본 호출 로그·프롬프트·입력 자산과 실험 Python 코드는 로컬에 보관한다.

## 리뷰 요청

측정 범위와 결론이 일치하는지, 실패 비용을 숨기지 않았는지,
품질 검수·manifest·외부 저장 경계를 유지하는지, Luna의 구현 순서와
작은 비교 시험의 선행 조건이 타당한지 검토한다.
새 코드가 아직 없다는 이유만으로 계획의 미구현 항목을 구현 버그로 취급하지 않는다.

설정 완료와 실제 리뷰 응답 완료는 구분하며, PR 타임라인의 봇 응답이 실행 증거다.

이 PR에서는 자동 merge, 자동 코드 수정, 운영 실행을 설정하지 않는다.
원격 CI와 Codex 리뷰는 별개이며, 로컬 문서·JSON 검사 성공을 원격 CI 성공으로 표시하지 않는다.
설정 방법은 [OpenAI 공식 GitHub 리뷰 안내](https://learn.chatgpt.com/docs/third-party/github)를 따른다.

커밋 `95684d6`을 push한 뒤 Codex 봇의 리뷰 요약에서 `New commits`로 실행되는 것을 확인했다.
수동 댓글뿐 아니라 새 커밋에 따른 자동 실행도 확인된 상태다. 각 revision의 검토 결과는 별도로 확인한다.
