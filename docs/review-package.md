# 계획과 벤치마크 결과의 PR 검토 범위

이 PR은 생성 속도 최적화 계획과 조립 예비시험 결과를 검토하기 위한 문서 변경이다.
최적화 구현이나 운영 전환을 포함하지 않는다. GPT-6 Astra가 계획을 갱신하고,
사용자가 구현을 요청하면 GPT-6 Luna가 로컬 프로젝트에서 구현할 예정이다.

## 원격 코드와 로컬 조사 자료의 차이

- PR 기준 커밋: `776ba8db3c2da97edeea6d36a427ec481b838da0` (`origin/main`).
- 조사한 로컬 HEAD: `053e48a`. 원격보다 앞선 기존 커밋 8개와 추가 미커밋 변경이 있다.
- Plan.md와 제안서는 그 로컬 작업 트리를 조사한 문서다. `기존 대상`으로 적힌
  일부 파일은 이 PR의 원격 checkout에 없으며, 원격 현재 상태의 실행 보증이 아니다.
- 기존 커밋·미커밋 운영 코드·실험용 Python 코드는 이번 PR로 일괄 게시하지 않는다.
  후속 구현 PR은 필요한 기준 코드를 먼저 검토해 반영한 뒤 별도로 만든다.
- 원래 프로젝트의 변경·로그·이미지·생성 글은 그대로 보존한다.

## 포함된 증거

Plan.md, 최적화 제안서, 조립 시험 규칙, 두 모델 호출의 요약 JSON,
프로그램 5회 측정 JSON과 상세 보고서를 포함한다. 수치는 원자료와 대조했다.
프로그램 실행 중앙값은 0.685초지만 두 모델 실행이 모두 검증에 실패하여
유효한 절감률은 없다. 전체 20~30%·중심 25%는 미검증 예상이다.

`benchmarks/assembly_smoke/protocol.md`는 로컬 실험 규칙을 보존한 문서다.
그 안의 실행 명령은 실험 코드와 입력 자산이 있는 원래 로컬 프로젝트용이며,
이번 PR의 checkout만으로 재현할 수 있다는 뜻이 아니다.
보고서에 언급한 원본 호출 로그·프롬프트·입력 자산과 실험 Python 코드는 로컬에 보관한다.

## 리뷰 요청

측정 범위와 결론이 일치하는지, 실패 비용을 숨기지 않았는지,
품질 검수·manifest·외부 저장 경계를 유지하는지, Luna의 구현 순서와
작은 비교 시험의 선행 조건이 타당한지 검토한다.
새 코드가 아직 없다는 이유만으로 계획의 미구현 항목을 구현 버그로 취급하지 않는다.
