# stage/naver-rider — intend.md

> **문서 목적:** 이 워크플로가 왜 존재하고 언제 완료로 판정되는지 기록합니다. 이 문서는 실행 명령이나 권한 승인서가 아니며, `AGENTS.md`·`BETA-AGENTS.md`·승인 Gate·기존 스키마가 우선합니다.

## 목적
사람 검수가 끝난 글을 네이버 편집기에 입력한 뒤 사용자 재확인을 받아 임시저장한다.

## 시작 조건
- 정식(`formal`) 모드이고 Notion 저장 Q2 재조회가 통과한다.
- Q3 사람 검수와 Gate B (`naver_draft_save`) 승인, page ID·대상 블로그·digest가 일치한다.

## 입력
- 검증된 Notion 페이지와 `final/[키워드]-naver-copy.md`
- 이미지·썸네일·Gate B 승인 기록

## 처리 및 산출물
- 모바일 편집 모드를 확인하고 제목·본문·표·이미지 블록을 검증된 순서로 입력한다.
- 임시저장 직전 사용자에게 확인을 받고 임시저장 목록에서 결과를 재확인한다.

**출력**
- 네이버 블로그 임시저장 글 제목 및 확인 증거
- 실행 로그와 누락·오류 사유

## 검증·완료 조건
- 제목·본문·이미지·대표 이미지가 원본과 같고 임시저장 결과를 확인한다.
- 발행이나 예약 발행을 실행하지 않았음을 검증한다.

## 금지·중단 조건
- 베타 모드에서는 호출하지 않는다.
- Gate B 없이 편집기 변경·업로드를 시작하지 않으며 사용자 최종 확인 없이 임시저장하지 않는다.
- 발행·예약 발행·공개 설정 변경 금지.

## 현재 구현 상태
현재 로컬 `naver-publish` 작업은 Gate B 요구로 `blocked` 반환한다. 네이버 로그인·본문 입력·임시저장 통합은 로컬 runner에 구현되지 않았다.
