# stage/image-maker — intend.md

> **문서 목적:** 이 워크플로가 왜 존재하고 언제 완료로 판정되는지 기록합니다. 이 문서는 실행 명령이나 권한 승인서가 아니며, `AGENTS.md`·`BETA-AGENTS.md`·승인 Gate·기존 스키마가 우선합니다.

## 목적
본문에 실제 정보를 추가하는 이미지와 별도 썸네일을 만들고 출처·권리·품질을 기록한다.

## 시작 조건
- 검증된 초안과 시각 슬롯 계약이 있다.
- 공식/허가 자산 우선 원칙과 생성 허용 여부가 정해져 있다.

## 입력
- `drafts/[키워드].md`의 이미지 마커
- 리서치의 이미지 출처·권리·시각 의도

## 처리 및 산출물
- 슬롯별 이미지 후보를 생성하거나 권리 확인된 자료를 사용한다.
- 이미지 순서·생성 메타데이터·출처와 전용 썸네일을 `image-map.md`에 기록한다.

**출력**
- `assets/[키워드]/`의 본문 이미지·`thumbnail.png` 또는 JPEG
- `assets/[키워드]/image-map.md`

## 검증·완료 조건
- 모든 필수 슬롯에 연결된 실제 파일이 있으며 경로·내용·권리 정보가 일치한다.
- 썸네일과 본문 이미지 역할이 구분되고 사람 검수 기준을 충족한다.

## 금지·중단 조건
- 확인되지 않은 실존 인물·제품·공식 화면을 사실처럼 합성하지 않는다.
- 검수 실패 자산과 빈 파일을 정상 산출물로 기록하지 않는다.

## 현재 구현 상태
에이전트 지침에 이미지 제작·품질 검사 계약이 있다. 로컬 실행기는 이미지 생성/첨부를 직접 수행하지 않는다.
