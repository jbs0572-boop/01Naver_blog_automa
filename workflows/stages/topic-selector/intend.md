# stage/topic-selector — intend.md

> **문서 목적:** 이 워크플로가 왜 존재하고 언제 완료로 판정되는지 기록합니다. 이 문서는 실행 명령이나 권한 승인서가 아니며, `AGENTS.md`·`BETA-AGENTS.md`·승인 Gate·기존 스키마가 우선합니다.

## 목적
사용자 요청과 검색 의도에 맞는 주제를 정하고, 조사 범위와 제목의 약속을 명시한다.

## 시작 조건
- 사용자가 정한 주제는 임의로 바꾸지 않는다.
- 중복 주제와 재베타 요청을 구분하고 기존 산출물의 존재를 확인한다.

## 입력
- 블로그 분야·독자·발행 목적·사용자 주제 또는 자동 선정 조건
- 기존 주제·베타 항목의 중복 여부

## 처리 및 산출물
- 주요 검색 질문, 대표 키워드, 제목이 약속하는 항목을 정한다.
- 총정리의 필수 항목, 독창적 정보 구조, 시각 슬롯 필요성을 먼저 정리한다.

**출력**
- `research/topic-selection-[키워드].md`

## 검증·완료 조건
- 선정된 주제와 사용자 요청이 일치한다.
- 제목 약속, 최신성 기준, 확인 항목과 미확인 항목이 구분되어 있다.

## 금지·중단 조건
- 중복·권리·필수 입력 미확인 상황을 성공으로 기록하지 않는다.
- 기존 주제 파일 또는 Notion 항목을 승인 없이 덮어쓰지 않는다.

## 현재 구현 상태
기존 에이전트 지침에는 실제 주제 선정 절차가 있다. 그러나 로컬 `daily-generate` 실행기는 이 단계에서 문서 생성을 실행하지 않고 단계 순서만 `passed`로 기록한다.
