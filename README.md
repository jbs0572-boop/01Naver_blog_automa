# 네이버 블로그 자동화

Codex로 주제 선정, 조사, 글·이미지 제작, 품질 검수, Notion 저장과 네이버 임시저장을 이어가는 프로젝트다.
현재 개선 목표는 **글·이미지 품질을 유지하거나 높이면서 생성 시간과 반복 실패 비용을 줄이는 것**이다.
Codex 자동 코드 리뷰는 이 목표를 지원하는 개발 검토 기능이다.

## 프로젝트와 변경의 관계

이 저장소에서 기존 시스템의 개선을 관리한다. 작업마다 만드는 브랜치와 Pull Request(PR)는
같은 프로젝트에 반영할 변경안이다. GitHub의 `#1` 같은 표시는 변경 요청 번호이며 프로젝트 이름이 아니다.

개발 흐름은 `개선 계획 → 작업 브랜치에서 구현·검증 → PR과 Codex 자동 리뷰 → 검토 후 main 반영`이다.
PR에는 변경 목적을 제목으로 적는다. 자동 리뷰 완료는 병합이나 운영 적용을 뜻하지 않는다.
현재 변경안은 실행 계획·벤치마크 근거·리뷰 규칙을 포함하며, 최적화 운영 구현은 아직 시작하지 않았다.

## 코드 리뷰의 역할과 현재 기준

자동 리뷰는 품질 검수·산출물 무결성·저장 안전성의 회귀와 중복 실행 등 실제 결함을 검토한다.
생성 글의 Q1·Q2 검수나 실제 운영 입력을 사용한 속도 비교를 대신하지 않는다.

현재 GitHub의 기준 코드는 조사한 로컬 운영 코드보다 이전 버전이다. 계획이 참조하는 최신 로컬 계약과
원격 AGENTS.md 사이에 Q3의 필수 여부와 최종 파일 개수 등의 차이가 있다.
실제 구현 전에 [검토 범위](docs/review-package.md)에 따라 코드·운영 계약의 기준을 맞춰야 한다.
예전 계약에 근거한 리뷰 지적을 그대로 적용해 최신 운영 규칙을 되돌리지 않는다.
